# 出题机制：有放回随机 + 不连出，答错整轮重来 + 同关卡加权错题池，首版不做 SR/自适应

#4 已锁轮次题量与阈值（快答 12 题 ≥90% 且中位响应 ≤3s、弹奏 8 题 ≥85%），本 ADR 锁定出题机制。题目从关卡**题池**中**有放回随机抽样**，附加**不连出**约束（相邻两题不相同）：统一机制同时适配小题池（首调功能音组 L1 仅 do-mi-so 三音、地标 L1 仅中央 C）与大题池（全键盘快答）；不要求轮内全覆盖，覆盖由关卡递进承担；固定序被否，因其训练顺序记忆而非识谱。答错**仅行内反馈不补出**（✓/✗ + 音名 + 响应毫秒，ADR 0002），轮末结算，未达标**整轮重来**——分母恒为 12/8，正确率与响应中位数口径不被补出题稀释，重来本身即最直接的错题再暴露。同一关卡的重来/复习轮启用**加权错题池**：上一轮错题以 3× 权重被抽中，答对一次即移出；池的生命周期止于该关卡轮次达标，不做跨天持久化。**间隔重复（SR）与自适应难度首版不引入**：SR 的记忆衰减前提与已锁定的「关卡通过永久有效不衰减」直接矛盾，自适应难度与「内容即难度参数、教学关卡顺序即难度递进」的教学立场冲突，复习需求已由自由复习已解锁关卡覆盖。但用户明确将两者列为**后续迭代的既定方向**，据此对后端领域模型（#6）施加约束：逐题作答历史（含错题记录与响应时间）须持久化，作为未来 SR 调度与自适应算法的原始数据基础；首版仅用于统计展示，不做任何自动调度。未来启动 SR/自适应属重划目的地的新 effort，不是本图延伸。
