# 产品信息架构：教科书式（课程树 + 长文教程 + 内容区训练）

工单 #5 的粗原型（分支 `prototype/teaching-training-flow`）对比了三个结构性变体：A 教科书式、B 关卡地图式（游戏化路径 + 全屏快答）、C 分屏工作台（参考资料与练习常驻分屏）。用户选定 **A**：侧栏课程树（主线/支线技巧与关卡状态）+ 长文教程页（正文 + 内嵌五线谱/键盘图）+ 内容区内训练与结算；训练反馈为**行内文字**（否掉 B 的全屏闪反馈与 C 的浮动 toast）；桌面与琴旁平板双场景用**单一响应式布局**承接（平板下课程树收为抽屉），不做设备独立布局。理由：产品定位是初学者的"学习工具"，教程的系统可读性与进度的可追溯性优先于游戏化刺激；信息架构一旦进入实现再改成本最高，故记录。
